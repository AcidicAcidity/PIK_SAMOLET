# «Новый Горизонт» — сайт застройщика жилья

Учебный full-stack проект: информационный сайт девелопера с каталогом квартир, личным кабинетом,
программой лояльности, ипотекой, бронированием и ролевой моделью.

| Слой | Технологии |
|---|---|
| Фронтенд | React 19, React Router 7, Vite 8, Axios, lucide-react (своя дизайн-система на CSS) |
| Бэкенд | Django 5.2, Django REST Framework, SimpleJWT, django-filter |
| БД | PostgreSQL 16 |
| Инфраструктура | Docker Compose: postgres, backend (gunicorn), frontend (nginx), Mailpit (почта для 2FA) |

---

## Запуск одной командой (macOS / Linux)

**Проще всего:** дважды щёлкните `start.command` в Finder (или выполните `./start.sh` в Терминале).

Скрипт сам выберет способ запуска:

- **Docker Desktop установлен** → поднимет всё через Docker Compose (PostgreSQL, бэкенд, фронтенд,
  почтовый ящик Mailpit) и откроет сайт. Первый запуск занимает 3–5 минут.
- **Docker нет** → запустит проект напрямую: проверит Python 3.10+, Node.js 22 и PostgreSQL
  (при наличии Homebrew недостающее установит сам), создаст базу, установит зависимости,
  заполнит демо-данными и откроет сайт. Коды для входа печатаются прямо в окне Терминала.

| Режим | Сайт | Коды 2FA |
|---|---|---|
| Docker | http://localhost:3000 | почтовый ящик Mailpit: http://localhost:8025 |
| Без Docker | http://localhost:5173 | зелёная строка в окне Терминала |

Другие команды: `./start.sh docker`, `./start.sh local`, `./start.sh stop` (остановить Docker).

## Запуск через Docker вручную

```bash
cp .env.example .env          # при необходимости поменяйте значения
docker compose up --build
```

| Что | Адрес |
|---|---|
| Сайт | http://localhost:3000 |
| Почта (коды 2FA) — Mailpit | http://localhost:8025 |
| REST API | http://localhost:3000/api/ (или напрямую http://localhost:8000/api/) |
| Django admin | http://localhost:3000/django-admin/ |

При первом запуске база автоматически заполняется демо-данными (4 ЖК, ~230 квартир, ипотечные программы, новости).

| Роль | Email | Пароль |
|---|---|---|

## Запуск без Docker (для разработки)

Нужны Python 3.11+, Node 20+, PostgreSQL.

```bash
# 1. База
createdb developer

# 2. Бэкенд
cd backend
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export POSTGRES_PASSWORD=ваш_пароль                    # см. переменные в config/settings.py
# Коды 2FA будут печататься в консоль:
export EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
python manage.py migrate
python manage.py seed_demo
python manage.py runserver

# 3. Фронтенд (в другом терминале)
cd frontend
npm install
npm run dev            # http://localhost:5173 — запросы /api проксируются на :8000
```

Тесты API (18 шт., работают на PostgreSQL):

```bash
cd backend && python manage.py test core
```

## Что реализовано

### Большая информационная страница застройщика (`/`)
Hero с быстрым подбором квартиры, анимированная статистика, о компании и миссия, карточки ЖК,
преимущества, «5 шагов до ключей», промо ипотеки и программы лояльности, таймлайн истории,
отзывы и награды, новости, FAQ, форма обратного звонка и контакты. Весь контент редактируется
в Django admin (модель «Информация о компании»).

### Каталог квартир (`/apartments`)
- Карточки: цена (и цена с персональной скидкой), площадь, комнатность, этаж, отделка, срок сдачи.
- Фильтры: ЖК, комнаты, цена, площадь, этаж, отделка, балкон, «не первый этаж», только свободные.
- Сортировка, пагинация, вид «плитка/список». Фильтры хранятся в URL — ссылкой можно поделиться.

### Страница квартиры (`/apartments/:id`)
Сгенерированная SVG-планировка (или загруженное изображение), положение на этаже, полные
характеристики, информация о ЖК и готовности корпуса, цена со скидкой, мини-калькулятор ипотеки,
онлайн-бронирование, заявка на консультацию, похожие квартиры.

### Личный кабинет (`/account`)
Карта лояльности и прогресс до следующего уровня, брони со статусами, заявки на ипотеку,
избранное, профиль и смена пароля.

### Программа лояльности (`/loyalty`)
Уровни (Старт 1% → Серебро 2% → Золото 3,5% → Платина 5%) рассчитываются автоматически по сумме
завершённых сделок. Скидка применяется к ценам в каталоге и фиксируется в брони.
Администратор может назначить уровень вручную и менять условия уровней.

### Ипотека (`/mortgage`)
Программы банков-партнёров, калькулятор аннуитетного платежа (расчёт на бэкенде), график выплат
по годам (диаграмма + таблица), валидация условий программы, подача заявки из кабинета,
обработка заявки менеджером.

### Двухфакторная аутентификация через email
1. `POST /api/auth/login/` — проверка пароля → на почту уходит код, в ответе `challenge_id`.
2. `POST /api/auth/verify/` — проверка кода → выдаются JWT (access + refresh).

Коды хранятся только в виде хеша, живут 10 минут, одноразовые, максимум 5 попыток,
повторная отправка не чаще раза в минуту, на auth-эндпоинтах включён throttling.
Регистрация и восстановление пароля также подтверждаются кодом из письма.

### Ролевая система
| Роль | Возможности |
|---|---|
| Клиент | каталог, избранное, сравнение, бронирование, ипотека, лояльность |
| Менеджер | + панель `/manager`: сводка, обработка броней (подтвердить/отклонить/завершить сделку), ипотечные заявки, обращения, редактирование цен и статусов квартир |
| Администратор | + панель `/admin`: пользователи и роли, блокировка, уровни лояльности, ипотечные программы, Django admin |

Права проверяются на бэкенде (`accounts/permissions.py`), фронтенд дополнительно скрывает
недоступные разделы.

### Фотографии
Обложки и галереи ЖК, а также фото квартир (интерьеры подбираются по типу отделки) — реальные
фотографии с Unsplash (лицензия Unsplash License, бесплатное использование). Они загружаются по ссылке,
поэтому нужен интернет; без него вместо фото автоматически показываются иллюстрации и планировки.
Любое фото можно заменить в Django admin: «Жилые комплексы» / «Квартиры» → блок «Фото» — загрузите файл
или вставьте другую ссылку.

### Дополнительно
- **Бронирование**: заявка → подтверждение менеджером (цена фиксируется на 14 дней) → сделка.
  Квартира автоматически меняет статус; просроченные брони снимаются автоматически;
  не более 3 активных броней на клиента; защита от двойного бронирования на уровне БД.
- **Избранное и сравнение** до 4 квартир с подсветкой лучших значений.
- **Жилые комплексы и корпуса** со стадиями и процентом готовности.
- **Новости и акции**, **заявки на обратный звонок**.
- **Email-уведомления** клиенту при смене статуса брони/заявки.
- Адаптивная вёрстка (десктоп / планшет / телефон).

## REST API (основное)

| Метод | URL | Доступ | Описание |
|---|---|---|---|
| POST | `/api/auth/register/` | все | регистрация → код на email |
| POST | `/api/auth/login/` | все | пароль → код на email |
| POST | `/api/auth/verify/` | все | код → JWT |
| POST | `/api/auth/resend/` | все | повторная отправка кода |
| POST | `/api/auth/refresh/` | все | обновление access-токена |
| POST | `/api/auth/password-reset/`, `/confirm/` | все | восстановление пароля |
| GET/PATCH | `/api/auth/me/` | клиент | профиль |
| GET | `/api/company/` | все | данные для страницы застройщика |
| GET | `/api/complexes/`, `/api/complexes/{slug}/` | все | ЖК |
| GET | `/api/apartments/?rooms=1,2&price_max=...&ordering=-price` | все | каталог с фильтрами |
| GET | `/api/apartments/{id}/` | все | квартира (цена со скидкой для авторизованных) |
| GET | `/api/apartments/facets/` | все | границы фильтров |
| POST/DELETE | `/api/apartments/{id}/favorite/` | клиент | избранное |
| GET | `/api/compare/?ids=1,2,3` | все | сравнение |
| GET/POST | `/api/bookings/`, POST `/api/bookings/{id}/cancel/` | клиент | мои брони |
| GET | `/api/loyalty/levels/`, `/api/loyalty/me/` | все / клиент | лояльность |
| GET | `/api/mortgage/programs/` | все | ипотечные программы |
| POST | `/api/mortgage/calculate/` | все | расчёт платежа |
| GET/POST | `/api/mortgage/applications/` | клиент | заявки на ипотеку |
| POST | `/api/leads/` | все | заявка на звонок |
| GET | `/api/manager/stats/` | менеджер | сводка |
| GET, POST `.../confirm|reject|complete/` | `/api/manager/bookings/` | менеджер | обработка броней |
| GET/PATCH | `/api/manager/mortgage/`, `/api/manager/leads/` | менеджер | заявки |
| PATCH | `/api/apartments/{id}/` | менеджер | цена/статус квартиры |
| GET/PATCH | `/api/admin/users/` | админ | пользователи и роли |
| PATCH | `/api/loyalty/levels/{id}/`, `/api/mortgage/programs/{id}/` | админ | настройки |

## Структура

```
backend/
  config/            настройки, маршруты
  accounts/          пользователь, роли, 2FA-коды, лояльность, права доступа
  catalog/           ЖК, корпуса, квартиры, избранное, фильтры
  bookings/          бронирование и жизненный цикл сделки
  mortgage/          программы, калькулятор, заявки
  core/              компания, новости, обращения, сводка, seed_demo, тесты
frontend/src/
  api/               axios-клиент с автообновлением JWT
  context/           авторизация, уведомления, сравнение
  components/        шапка, карточки, генератор планировок, иллюстрации ЖК, диаграммы
  pages/             страницы сайта, кабинет, панели менеджера и администратора
```

## Для продакшена
- Задайте `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, реальные `DJANGO_ALLOWED_HOSTS`.
- Подключите реальный SMTP (пример в `.env.example`).
- Раздавайте `/media/` через nginx или S3, включите HTTPS.
- Для истечения броней можно дополнительно запускать задачу по расписанию (сейчас проверка идёт при каждом запросе к броням).

> Все названия компаний, ЖК и банков — вымышленные; данные демонстрационные.
